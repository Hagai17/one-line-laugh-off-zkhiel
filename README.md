Entry for the [One-Line Laugh-Off](https://make.fun/b/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun: exactly one funny line, judged head to head.

## The line

> Dad watched the dog for one hour and returned him with a savings account, a bedtime, and a referral to his accountant.

## How it was picked

Twelve drafts were written, then dueled pairwise in both orders under the
competition's published judge brief (funniest > hardest laugh > surprise >
economy > freshness). The first champion lost to the strongest visible field
line, so the entry was iterated twice — the shipped line is a three-beat
escalation that beat the field's five strongest visible lines in both orders.
The full draft list, field sample, and duel record are in
[candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt and prints it
```
